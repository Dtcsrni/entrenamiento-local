# Pruebas de hardware

Las pruebas físicas deben registrar dispositivo, versión de OS/firmware, configuración, fecha, procedimiento, datos de entrada saneados y resultado.

Matriz inicial:

- Realme GT 6: lifecycle, cámara, profundidad, batería y rendimiento.
- Amazfit Active: API level, almacenamiento, mensajería y reconexión.
- Tezkatli: CPU/RAM/GPU, runtime, red, cola y recuperación.
- Red externa: acceso privado desde el gimnasio.
