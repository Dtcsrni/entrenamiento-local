# ADR-007 — Procedencia nutricional

- **Estado:** Accepted
- **Fecha:** 2026-08-12

## Decisión

Cada alimento y nutriente conservará fuente y calidad: laboratorio/gobierno, fabricante, comunidad verificada, comunidad no verificada, usuario o estimación de IA.

## Consecuencias

La búsqueda debe ponderar calidad además de coincidencia; los datos externos se normalizan mediante una capa anticorrupción.
