# ADR-009 — Gobierno de modelos

- **Estado:** Accepted
- **Fecha:** 2026-08-12

## Decisión

Versionar modelo, pesos, prompt, preprocesamiento, esquema y dataset. Promover manualmente solo después de superar una baseline definida.

## Consecuencias

- No habrá aprendizaje online automático.
- Los resultados serán reproducibles dentro de las limitaciones documentadas.
- Se conservará una ruta de rollback.
