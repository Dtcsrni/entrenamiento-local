# ADR-008 — Red privada hacia Tezkatli

- **Estado:** Proposed
- **Fecha:** 2026-08-12

## Decisión propuesta

Usar Tailscale para conectividad privada, backend enlazado a localhost/interfaz privada y autenticación adicional de aplicación. No usar Funnel ni abrir puertos públicos.

## Evidencia pendiente

- Conexión desde el gimnasio.
- Reconexión después de cambio Wi-Fi/datos.
- Modelo final de identidad y rotación de token.
