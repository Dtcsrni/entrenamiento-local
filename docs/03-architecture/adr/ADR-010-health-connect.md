# ADR-010 — Health Connect como adaptador

- **Estado:** Accepted
- **Fecha:** 2026-08-12

## Decisión

Health Connect será una integración opcional. La base propia seguirá siendo la autoridad para los detalles de entrenamiento, nutrición y suplementos.

## Consecuencias

Se conservará origen, método de registro e ID externo; la deduplicación no se delegará ciegamente a agregados externos.
