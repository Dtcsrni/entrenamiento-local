# Catálogos

Aquí se almacenarán manifiestos, esquemas y datos semilla cuya licencia permita versionarlos.

Cada catálogo debe declarar:

- Fuente y URL.
- Licencia.
- Fecha/versionado.
- Hash del artefacto original.
- Transformaciones.
- Calidad y cobertura.
- Política de actualización.

No incorporar exportaciones externas sin revisar licencia ni datos personales.
