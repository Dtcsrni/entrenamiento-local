# Inteligencia artificial

Este árbol contendrá pipelines, adaptadores, evaluación, prompts y registro de modelos. Los pesos y datos personales no se versionan.

Antes de añadir un modelo:

1. Revisar licencia y procedencia.
2. Medir compatibilidad con Tezkatli o Realme GT 6.
3. Registrar hash y requisitos.
4. Ejecutar baseline y golden set.
5. Documentar limitaciones y rollback.
